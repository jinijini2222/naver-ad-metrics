# secrets/ 폴더

API 키를 보관하는 폴더입니다. **이 폴더의 `README.md`와 `keys.env.example` 외에는 Git에 올라가지 않습니다** (루트 `.gitignore`).

## 사용법

1. 예시 파일을 복사해서 실제 값을 채웁니다.
   ```bash
   cp secrets/keys.env.example secrets/keys.env
   ```
2. 시트에서 **네이버 광고 → 2. API 키 입력**으로 네이버 키 3개를 입력합니다. Claude 키는 Apps Script 편집기에서 `setClaudeApiKey`를 실행해 입력합니다. 입력한 값은 Apps Script **스크립트 속성**에만 저장됩니다.
3. 스크립트는 이 폴더의 파일을 읽지 않습니다. `keys.env`는 사람이 값을 잃어버리지 않게 하는 보관용입니다.

## 지켜야 할 것

- 키를 코드, 시트, 문서, PR, 채팅(이 대화 포함)에 붙여 넣지 않습니다.
- 이 폴더는 로컬 컴퓨터에서만 쓰세요. 클라우드 세션(컨테이너)은 종료되면 사라지고, 세션 기록에 값이 남을 수 있습니다.
- 키가 노출됐다면 즉시 폐기하고 재발급합니다. 네이버는 광고주센터 API 사용 관리에서, Claude는 Anthropic 콘솔에서 합니다.
- 마케터에게 키를 받을 때도 메신저·메일 평문 대신 비밀번호 관리자나 일회성 공유 링크를 쓰세요.
