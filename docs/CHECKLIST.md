# 개발 과정 체크리스트

[PRD](PRD.md) 기반. 위에서부터 순서대로 진행하며, 각 단계 끝의 **완료 조건**을 만족해야 다음 단계로 넘어간다.
일정은 PRD 13절(5주 목표)에 맞춘다. 날짜는 착수일에 맞춰 조정한다.

| 단계 | 내용 | 주차 | 완료 조건 |
| --- | --- | --- | --- |
| 0 | 사전 준비 | 1주차 | API 키 발급, 필드명·엔드포인트 확정 |
| 1 | 시트와 인증 | 1주차 | 캠페인 목록이 로그에 출력됨 |
| 2 | 수집 | 2주차 | 지난주 소재별 노출·클릭이 원본 탭에 쌓임 |
| 3 | 매핑과 판정 | 3주차 | 판정 탭 자동 갱신 |
| 4 | 트리거와 알림 | 4주차 | 월요일 11:00 알림 수신 |
| 5 | AI 개선안 | 5주차 | 알림에 AI 개선안 포함 |
| 6 | 운영 점검 | 운영 4주 후 | 성공 기준 4개 점검, Phase 2 결정 |

---

## 0단계: 사전 준비

- [ ] 마케터에게 API 사용 목적과 조회 전용임을 설명하고 협조 요청
- [ ] 광고주센터에서 API 키, 비밀키, 고객 ID 발급 (마케터)
- [ ] 키 전달 방법 확정 (스크립트 속성에 직접 입력 또는 디자이너에게 안전하게 전달)
- [ ] 공식 API 문서(naver/searchad-apidoc)에서 stats 지표 필드명 확인
  - [ ] 예상 필드 대조: `impCnt`, `clkCnt`, `salesAmt`, `ccnt`, `convAmt`, `avgRnk`
- [ ] 공식 API 문서에서 캠페인·광고그룹·소재 목록 엔드포인트와 파라미터 확인
- [ ] 성과형 디스플레이 API 지원 범위 확인 (Phase 2 판단용)
- [ ] 키 발급 지연 시 대안 확정: 광고주센터 보고서 다운로드 + 드롭 폴더

**완료 조건:** API 키 3종 확보, 사용할 필드명과 엔드포인트 목록 확정

## 1단계: 시트와 인증

- [ ] 구글 시트 생성, 5개 탭 만들기
  - [ ] `네이버_원본`: 수집일, 기간시작, 기간종료, 광고 상품, 캠페인, 광고그룹, 소재 ID, 노출수, 클릭수, 광고비, 전환수, 전환매출, 평균 노출 순위
  - [ ] `매핑`: 작업물 ID, 네이버 소재 ID, 광고 상품, 게시일, 교체일, 메모
  - [ ] `판정`: 작업물 ID, 주차, CTR, 기준선, 판정비율, 판정, 전환율, CPC, ROAS, 순위 영향 여부, 3주 추이
  - [ ] `알림_로그`: 발송일, 작업물 ID, 알림 유형, AI 개선안 전문, 발송 대상
  - [ ] `설정`: 성공 기준(20%), 개선 기준(20%), 최소 노출(1,000), 순위 차(2), 알림 수신자, AI 사용 여부
- [ ] 원본·판정·알림_로그 탭은 스크립트만 쓰도록 보호 (사람은 매핑·설정만 수정)
- [ ] 확장 프로그램 → Apps Script 프로젝트 생성
- [ ] 스크립트 속성(PropertiesService)에 API 키·비밀키·고객 ID 저장 (시트·코드에 적지 않기)
- [ ] 시트 공유 대상에 키가 노출되지 않는지 확인
- [ ] 필드명을 설정 상수로 분리 (API 사양 변경 대비)
- [ ] HMAC-SHA256 서명 함수 작성 (`Utilities.computeHmacSha256Signature`, 타임스탬프·메서드·경로)
- [ ] 조회 전용 원칙 적용: 광고 생성·수정·입찰 변경 호출이 코드에 없음
- [ ] 캠페인 목록 조회 테스트, 로그 출력 확인

**완료 조건:** 캠페인 목록이 로그에 출력됨

## 2단계: 수집

- [ ] 광고그룹·소재 목록 조회, 소재 ID와 광고그룹 이름 표 만들기
- [ ] 광고 상품 구분 (쇼핑검색 / 파워링크 이미지형 확장소재 / 파워링크 텍스트 소재)
- [ ] 지난주 기간(월~일) 자동 계산 함수
- [ ] 소재 ID 묶음으로 stats 조회, 노출·클릭·비용·전환·순위 수집
- [ ] 목록과 성과를 소재 ID로 조인해 `네이버_원본`에 기록 (캠페인·광고그룹 이름 포함)
- [ ] 같은 기간·소재 ID 중복 시 덮어쓰기
- [ ] 2주 전 데이터 재조회로 늦게 잡힌 전환 반영
- [ ] 요청 사이 짧은 대기, 429·5xx 응답 재시도 3회
- [ ] 실행 시간 점검 (1회 최대 6분), 소재가 많으면 분할 방안 확인

**완료 조건:** 지난주 소재별 노출·클릭이 시트에 쌓임

## 3단계: 매핑과 판정

- [ ] 매핑 탭 입력 규칙 정리 (작업물 ID / 네이버 소재 ID / 광고 상품, 1:1)
- [ ] 쇼핑검색 썸네일 교체 규칙 정리 (교체 시 새 작업물 ID로 매핑, 교체일 기록, 이전 성과는 이전 ID에 유지)
- [ ] 기존 쇼핑검색 소재부터 매핑 입력
- [ ] 미매핑 소재 목록 자동 생성
- [ ] 지표 계산: CTR, 전환율, CPC, ROAS, 평균 노출 순위
- [ ] 광고 상품별 최근 4주 평균 CTR 기준선 계산 (상품별로 따로)
- [ ] 최소 노출 1,000 미만 → 데이터 부족, 판정 제외
- [ ] 성공(비율 ≥ 1.2) / 보통 / 개선 필요(비율 ≤ 0.8) 판정
- [ ] 평균 노출 순위 비교, 기준선 소재보다 2단계 이상 낮으면 순위 영향 표시
- [ ] 3주 추이로 소재 피로 판정 (3주 연속 하락, 첫 주 대비 20% 이상 감소)
- [ ] 파워링크 텍스트 소재는 수집만 하고 판정 제외
- [ ] 광고 상품별 소재 5개 미만이면 알림 끔
- [ ] 설정 탭 값으로 기준을 읽도록 연결 (코드에 하드코딩 금지)
- [ ] 기존 성과 기록 템플릿의 배너 시트가 판정 탭 값을 작업물 ID로 불러오도록 연결

**완료 조건:** 판정 탭 자동 갱신

## 4단계: 트리거와 알림

- [ ] 수집·판정·알림을 별도 함수로 분리
- [ ] 시간 트리거 등록: 월 09:00 수집, 10:30 판정, 11:00 알림
- [ ] 알림 메일 본문 템플릿
  - [ ] 제목: `[네이버 광고 알림] 기준 이하 소재 N건 (9/14~9/20)` 형식
  - [ ] 소재별 한 줄: 작업물 ID, 광고 상품, CTR과 기준선 대비 %, 순위 영향 표시
  - [ ] 소재별 규칙 기반 진단 한 줄
  - [ ] 미매핑 소재 목록
  - [ ] 판정 탭 링크
- [ ] 알림 대상: 개선 필요 + 소재 피로 (판정이 보통이어도 피로면 포함)
- [ ] MailApp 발송, 수신자는 설정 탭에서 읽기
- [ ] 수집 실패 시 디자이너에게 오류 메일 1통 + `알림_로그` 기록
- [ ] 수집 실패 시 이전 주 데이터로 판정하지 않기
- [ ] 발송 내역을 `알림_로그`에 기록
- [ ] 한 주 동안 테스트 수신자에게만 발송해 검증

**완료 조건:** 월요일 11:00 알림 수신

## 5단계: AI 개선안

- [ ] Claude API 키를 스크립트 속성에 저장
- [ ] 프롬프트 작성
  - [ ] 입력: 작업물 ID, 광고 상품, CTR·전환율·순위, 3주 추이, 규칙 기반 진단
  - [ ] 출력: 원인 가설 1~2문장, 수정 제안 3개, 다음 A/B 테스트 1개, 디자인 외 요인 주의 1문장
  - [ ] 순위 영향 표시 소재는 주의 문장에 "입찰·순위 확인 먼저" 반드시 포함
- [ ] 알림 대상 소재만 호출 (주 5건 내외)
- [ ] 설정 탭의 AI 사용 여부가 꺼져 있으면 호출하지 않기
- [ ] 결과를 `알림_로그`에 전문 저장, 메일에 첨부
- [ ] API 오류 시 AI 개선안 없이 알림은 정상 발송

**완료 조건:** 알림에 AI 개선안 포함

## 6단계: 운영 점검

- [ ] 운영 4주 후 성공 기준 4개 점검
  - [ ] 마케터 주간 수동 입력 0분
  - [ ] 자동 수집 성공 4주 중 4회
  - [ ] 매핑률: 판정 대상 소재의 90% 이상
  - [ ] 알림 소재 중 1건 이상이 교체 또는 A/B 테스트로 이어짐
- [ ] 판정 기준값(±20%, 최소 노출, 순위 차) 조정
- [ ] 마케터에게 결과 공유
- [ ] Phase 2(성과형 디스플레이) 진행 여부 결정

**완료 조건:** 성공 기준 점검 결과를 바탕으로 Phase 2 결정

## 리스크 확인 (상시)

- [ ] CTR이 순위·키워드에 흔들리는 문제: 순위 영향 표시와 같은 광고 상품끼리 비교가 동작하는가
- [ ] API 사양 변경: 오류 메일이 즉시 발송되는가
- [ ] 매핑 누락: 미매핑 목록이 알림 메일 하단에 포함되는가
- [ ] 개인정보: 고객 정보 없이 광고 성과 수치만 저장하는가
