# 개발 과정 체크리스트

[PRD](PRD.md) 기반. 2026-11-02에 마케터가 **네이버 검색광고 API 키만 발급 가능**하다고 확인해, API 방식으로 진행한다. 키가 필요한 실제 호출 검증은 키를 받은 뒤로 미루고, 나머지를 먼저 개발했다.

**표기**: `[x]` 완료 · `[~]` 코드 작성·가짜 환경 테스트 통과, 실제 시트/API 미검증 · `[ ]` 미착수 · `[-]` 보류(대안 방식)
7단계 항목의 꼬리표: **(키 불필요)** 지금 개발 가능 · **(키 필요)** API 키가 있어야 검증 · **(확인 필요)** 문서·계정으로 먼저 확인

테스트: `node tests/verdict.test.js`, `collect.test.js`, `alert.test.js`, `ai.test.js`, `mapping.test.js`, `banner.test.js`, `report.test.js`, `itemreport.test.js`, `priority.test.js`, `report.render.test.js`·`draft.render.test.js`(Chromium 필요), `manifest.test.js`, `e2e.test.js` (모두 가짜 환경, 네이버·Claude 호출 없음). `e2e`는 가짜 스프레드시트로 초기화 → 데모 → 판정 → 알림 → 오류 경로 → 삭제를 실행한다.
