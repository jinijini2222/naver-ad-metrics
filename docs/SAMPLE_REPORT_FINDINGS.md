# 샘플 보고서 확인 결과 (2026-11-02)

광고주센터에서 내려받은 보고서 2개를 확인했습니다. 원본 CSV는 상품명·캠페인명이 들어 있어 이 저장소에 넣지 않았고, 구조와 집계 결과만 적습니다. 보고서 업로드 방식(PRD 6-2)과 API 방식 모두에 영향이 있습니다.

## 1. 월간 보고서 raw

| 항목 | 내용 |
| --- | --- |
| 형식 | UTF-8(BOM), 1행 제목(`…월간보고서_raw(기간),번호`), 2행 헤더, 3행부터 데이터. 8,705행 |
| 열 15개 | 캠페인, 캠페인유형, 광고그룹, 소재, 검색/콘텐츠 매체, 매체이름, 주별, 요일별, 노출수, 클릭수, 총비용, 총 전환수, 총 전환매출액(원), 구매완료 전환수, 구매완료 전환매출액(원) |
| 단위 | 소재 × 매체 × 주 × 요일. 소재×주로 **합산**해야 함 (소재×매체×주×요일 키가 겹치는 행이 17건 있어 덮어쓰기가 아니라 합산) |
| 소재 열 | 소재 **ID**(`nad-a001-02-…`)만 있고 이름·이미지 정보는 없음. 82개 |
| 주별 | `2026.10.05.(월)주` 형식, 월요일 시작이라 판정의 주 정의와 같음 |
| 숫자 | 쉼표 없는 정수 |

관찰한 점:
- 기간을 10/01~10/31로 받았는데 포함된 주는 3개(10/05, 10/12, 10/19)입니다. 월~일이 기간 안에 **완전히 들어오는 주만** 들어 있습니다. 월간 보고서로는 월말 주가 빠지므로, 주간 운영에는 **지난주 월~일**로 기간을 지정해 받아야 합니다.
- 캠페인유형은 `쇼핑검색`(소재 ID 접두사 `nad-a001-02`)과 `브랜드검색/신제품검색`(`nad-a001-04`) 두 가지뿐입니다. **파워링크와 확장소재는 없습니다.**
- **평균 노출 순위 열이 없습니다.**
- 전환이 두 종류입니다: `총 전환수`(합 482)와 `구매완료 전환수`(합 143)는 약 3.4배 차이가 납니다.

소재×주로 합산한 뒤 노출 1,000 이상인 소재 수:

| 주 | 쇼핑검색 | 브랜드검색/신제품검색 |
| --- | --- | --- |
| 10/05 | 19 / 69개 | 1 / 8개 |
| 10/12 | 16 / 66개 | 0 / 8개 |
| 10/19 | 12 / 59개 | 0 / 9개 |

노출 1,000 이상인 쇼핑검색 소재의 CTR 중앙값은 주마다 약 1.4~1.5%입니다.

## 2. performance_20261026_20261101.csv

2줄 머리글(`조회기간 : …`, `date,총 노출수,총 클릭수,총 전환수`) 아래에 **일별 합계**만 있습니다(쉼표가 든 숫자는 따옴표로 감쌈). 소재 단위가 아니라서 판정에는 쓸 수 없습니다. 7일 합계는 노출 582,169, 클릭 2,573(CTR 0.44%)로, 월간 보고서의 쇼핑검색 주간 합계(노출 약 4.6만~8.3만, CTR 2.1~2.5%)와 규모와 CTR이 크게 다릅니다. 계정 전체(다른 캠페인 유형 포함)로 보이지만, 이 두 파일만으로는 확인되지 않습니다. 쓸 수 있다면 수집 후 주간 합계를 대조하는 검증용 정도입니다.

## 3. 영향과 결정이 필요한 것

| 발견 | 영향 | 제안 |
| --- | --- | --- |
| 평균 노출 순위 없음 | 보고서 방식에서는 `순위 영향 가능` 표시를 쓸 수 없음 (쇼핑검색은 API에서도 순위 값이 의미 없음) | 쇼핑검색은 순위 비교 없이 판정. 순위가 필요하면 파워링크를 API로 |
| 파워링크·확장소재 없음 | 이 계정의 Phase 1은 사실상 **쇼핑검색만** | 마케터에게 파워링크 집행 여부 확인 |
| 브랜드검색/신제품검색 | PRD 범위 밖이고 노출이 적어 판정 불가 | 수집 대상에서 제외 |
| 노출 1,000 미만 소재가 쇼핑검색의 약 73~80% | 최소 노출 기준을 그대로 두면 대부분 `데이터 부족` | 최소 노출 값(설정 탭) 조정, 또는 노출 많은 소재부터 매핑 |
| 소재 ID = 상품 단위, 82개 | 매핑 대상이 많음 | 노출 상위 소재부터 매핑 (가장 중요) |
| 전환이 두 종류 | 전환율·ROAS 기준이 달라짐 | **결정 필요**: 총 전환수(PRD 기본) vs 구매완료 |

## 4. 디자인 우선순위 임계값 모의 실행 (쇼핑검색 8개 캠페인 × 3주)

초기값(광고비 비중 10%, 클릭 100, 전환율 0.5%, 노출 -50%)으로 PRD 15-2 규칙을 이 샘플에 적용한 결과입니다. 전환은 총 전환수 기준입니다.

| 주 | 규칙 A (비용 크고 전환율 낮음) | 규칙 B (노출 급감) |
| --- | --- | --- |
| 10/05 | 0건 | 0건 (전주 데이터 없음) |
| 10/12 | 0건 | 2건 |
| 10/19 | 0건 | 1건 |

- 규칙 A가 걸리지 않는 이유: 광고비 비중 상위 캠페인의 총 전환율이 약 3~13%입니다. 전환율 기준을 1%로 완화하거나 최소 클릭을 50으로, 비중을 5%로 낮춰도 결과가 같습니다.
- 광고비 비중 상위 캠페인 중 일부는 주간 클릭이 70~90대라 최소 클릭 100에 미달합니다.
- 규칙 A를 이 계정에서 쓰려면 전환율 기준을 올리거나(예: 3%), 계정 평균 대비 상대 기준으로 바꿔야 합니다.
