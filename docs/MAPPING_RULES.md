# 매핑 탭 입력 규칙

매핑 탭은 **네이버 광고 소재 ID**와 **디자인 작업물 ID**를 연결하는 표입니다. 디자이너가 작성하고, 판정은 이 표를 기준으로 성과를 작업물에 배정합니다. 규칙을 어기면 성과가 엉뚱한 작업물에 들어가거나 판정에서 빠집니다.

## 열별 규칙

| 열 | 필수 | 입력 방법 |
| --- | --- | --- |
| 작업물 ID | 예 | 디자인 작업물마다 하나. 공백 없이. 권장 형식 `{유형}_{월일}_{버전}` (예: `SH_1019_A` 쇼핑검색, `PI_1019_A` 파워링크 이미지). 디자인을 바꾸면 새 ID(`…_B`)를 쓰고, 같은 ID를 다른 디자인에 다시 쓰지 않습니다. `DEMO_`로 시작하는 ID는 데모 전용입니다 |
| 네이버 소재 ID | 예 | 광고 소재 ID 그대로(쇼핑검색·텍스트는 `nccAdId`, 확장소재는 `nccAdExtensionId`). 판정 실행 후 자동으로 추가되는 행에서 복사하면 틀리지 않습니다 |
| 광고 상품 | 권장 | 드롭다운에서 선택: 쇼핑검색 / 파워링크 확장소재 / 파워링크 텍스트. 계산에는 원본 탭의 값이 쓰이지만 점검을 위해 맞춰 둡니다 |
| 게시일 | 권장 | 이 작업물이 나가기 시작한 **월요일**. 비우면 처음부터로 봅니다 |
| 교체일 | 교체 시 | 이 작업물을 다른 것으로 바꾼 **월요일** (그 주부터 새 작업물). 교체 전에는 비워 둡니다 |
| 메모 | 선택 | 자유. 자동 추가 행에는 캠페인·광고그룹 이름과 사유가 들어갑니다 |
| 이미지 URL | 선택 | 소재 주간 리포트에 보일 이미지 주소(`https://…`). `=IMAGE()`로 표시되며 http(s) 주소만 쓰입니다. 구글 드라이브의 보기 링크는 이미지로 표시되지 않을 수 있으니 직접 이미지 주소를 쓰세요. 같은 작업물 ID의 행 중 처음 입력된 주소를 씁니다 |
| 규격(가로x세로) | 선택 | 예: `750x280`. 규격 점검(예정)에 쓰입니다 |

날짜는 **진짜 날짜**로 입력합니다 (`2026-10-19`). `2026.10.19`처럼 글자로 들어가면 비교가 어긋납니다. 시트가 드롭다운과 날짜 검사를 해 주지만, 붙여넣기는 막지 못하므로 **5-1. 매핑 점검**으로 확인하세요.

## 기본 원칙

1. **작업물 하나 = ID 하나.** 같은 디자인이면 같은 ID, 새 디자인이면 새 ID입니다.
2. **같은 소재 ID의 기간은 겹치지 않고 이어집니다.** 이전 작업물의 교체일 = 새 작업물의 게시일입니다.
3. **날짜는 월요일.** 판정은 월~일 주 단위라서, 주 중간 날짜를 쓰면 그 주 전체가 한쪽에 들어갑니다.
4. **한 작업물 ID에는 한 가지 광고 상품만.** 같은 작업물을 여러 소재(광고그룹)에 쓰는 것은 괜찮고, 이때는 같은 ID로 행을 여러 개 만듭니다. 성과는 합산해서 CTR을 계산합니다.
5. **작업물 ID가 빈 행은 할 일입니다.** 노란색으로 표시됩니다.

## 판정이 매핑을 쓰는 방법

성과 한 주(월~일)의 **시작일**이 `[게시일, 교체일)` 안에 들어오는 작업물에 그 주 성과를 배정합니다.

소재 `nad-1`에 작업물 A(게시 10/05, 교체 10/19), 작업물 B(게시 10/19)를 매핑한 경우:

| 주 시작 | 배정 |
| --- | --- |
| 10/05 | A |
| 10/12 | A |
| 10/19 | B |
| 10/26 | B |

- 게시일 **이전** 주는 어떤 작업물에도 속하지 않아 판정에서 제외됩니다.
- 모든 행의 교체일이 지났는데 새 행이 없으면 **미매핑**으로 표시됩니다 (조용히 사라지지 않습니다).
- 주 중간에 교체했을 때는 새 디자인이 더 오래 나간 쪽으로 날짜를 맞춥니다.
  - **목요일까지** 교체: 그 주 월요일을 교체일로 적습니다 (그 주를 새 작업물로).
  - **금요일 이후** 교체: 다음 주 월요일을 교체일로 적습니다 (그 주를 이전 작업물로).

## 상황별 입력 예시

### 1. 새 소재를 게시했을 때
1. **5. 판정 실행**을 누르면 매핑 탭 맨 아래에 작업물 ID가 빈 노란 행이 생깁니다.
2. 작업물 ID와 게시일(월요일)을 채웁니다.

### 2. 쇼핑검색 썸네일을 교체했을 때 (같은 소재 ID)

| 작업물 ID | 네이버 소재 ID | 광고 상품 | 게시일 | 교체일 |
| --- | --- | --- | --- | --- |
| SH_1005_A | nad-1 | 쇼핑검색 | 2026-10-05 | **2026-10-19** |
| SH_1019_B | nad-1 | 쇼핑검색 | **2026-10-19** | |

이전 행에 교체일을 적고, 같은 소재 ID로 새 행을 추가하면서 게시일을 같은 날짜로 적습니다. 교체일 이전 성과는 이전 작업물에 남습니다.

새 행을 만들지 않고 넘어가면, 다음 **판정 실행** 때 `교체 후 새 작업물 등록 필요`라는 메모가 달린 노란 행이 자동으로 추가되고 최신 주 매핑률이 내려갑니다.

### 3. 파워링크 이미지 확장소재를 바꿨을 때
- 새 확장소재가 **새 소재 ID**로 생기면: 새 소재이므로 새 행을 추가합니다. 이전 소재는 노출이 0이 되어 데이터 부족으로 표시됩니다.
- **같은 소재 ID**에서 이미지만 바뀌면: 2번과 같이 처리합니다.
- 어느 쪽인지는 API 키를 받은 뒤 실제 계정에서 확인합니다.

### 4. 같은 디자인을 여러 광고그룹에 쓸 때

| 작업물 ID | 네이버 소재 ID |
| --- | --- |
| SH_1019_A | nad-1 |
| SH_1019_A | nad-2 |

같은 작업물 ID로 행을 여러 개 만듭니다. 두 소재의 성과를 합산해 판정합니다.

### 5. 광고를 중단했을 때
교체일을 적을 필요가 없습니다. 노출이 사라지면 `데이터 부족`으로 표시됩니다.

### 6. 입력 실수를 고칠 때
매핑을 고친 뒤 **5. 판정 실행**을 다시 누르면 판정 탭 전체가 다시 계산됩니다.

## 자동 점검 (메뉴 5-1. 매핑 점검)

| 수준 | 항목 |
| --- | --- |
| 오류 | 네이버 소재 ID 없음 / 날짜가 날짜 형식이 아님 / 교체일이 게시일보다 이르거나 같음 / 같은 소재 ID의 기간 겹침(교체일이 비어 있는데 뒤에 다른 작업물이 있는 경우 포함) / 한 작업물 ID에 서로 다른 광고 상품 |
| 경고 | 날짜가 월요일이 아님 / 같은 소재 ID의 두 행 사이 기간 공백 / 작업물 ID에 공백 / 광고 상품이 목록에 없음 / 파워링크 텍스트에 작업물 ID를 적음(판정 제외) |
| 할 일 | 작업물 ID가 빈 행 (미매핑 소재) |

초기화(`1. 시트 초기화`)가 입력 제한도 설정합니다: 광고 상품 드롭다운, 날짜 검사, 작업물 ID가 빈 행 노란색 표시, 시트 시간대 `Asia/Seoul`.

## 자주 하는 실수

| 실수 | 결과 | 예방 |
| --- | --- | --- |
| 날짜를 글자로 입력 (`2026.10.19`) | 주 배정이 어긋남 | 날짜 검사, 매핑 점검 |
| 교체일만 적고 새 행을 안 만듦 | 그 주부터 판정에서 빠짐 | 자동으로 노란 행 추가 |
| 이전 행의 교체일을 안 적음 | 두 작업물의 기간이 겹침 | 매핑 점검(오류) |
| 새 디자인에 이전 작업물 ID를 재사용 | 두 디자인 성과가 섞임 | 디자인이 바뀌면 새 ID |
| 데모 행을 지우지 않음 | 기준선 오염 | 실제 수집 전 `10. 데모 데이터 지우기` |

## 매핑률

성공 기준은 **판정 대상 소재의 90% 이상 매핑**입니다. 판정 실행 시 실행 로그에 최신 주의 `매핑된 소재 / 전체 소재`가 출력됩니다.
