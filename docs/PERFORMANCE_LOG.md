# 성과기록_배너 탭 (임시 성과 기록 템플릿)

기존 성과 기록 템플릿이 없어 임시로 만든 탭입니다. 작업물 ID마다 한 줄이고, **판정 탭의 최신 주 결과**가 자동으로 채워집니다. 디자이너는 이름·조치·메모만 적으면 됩니다.

## 열

| 열 | 내용 | 작성 |
| --- | --- | --- |
| A 작업물 ID | 매핑 탭의 작업물 ID | 자동 추가(직접 추가도 가능) |
| B 작업물 이름 | 알아볼 수 있는 이름 (예: 추석 기획전 메인 배너) | 디자이너 |
| C 광고 상품 | 쇼핑검색 / 파워링크 확장소재 | 자동 |
| D 게시일 | 매핑 탭의 가장 이른 게시일 | 자동 |
| E 최근 주차 | 이 작업물의 가장 최근 판정 주(월요일) | 자동 |
| F CTR | 그 주 CTR | 자동 |
| G 기준선 CTR | 같은 광고 상품의 최근 4주 합산 CTR | 자동 |
| H 기준선 대비 | 판정비율 - 1 (예: -49%) | 자동 |
| I 판정 | 성공(초록) / 보통 / 개선 필요(빨강) / 데이터 부족(회색) | 자동 |
| J 전환율, K CPC, L ROAS | 그 주 값 | 자동 |
| M 순위 영향 | `순위 영향 가능` 표시 | 자동 |
| N 3주 추이 | `2.40% → 2.20% → 1.80%` | 자동 |
| O 알림 유형 | 개선 필요 / 소재 피로 (비어 있으면 알림 없음) | 자동 |
| P 조치 | 드롭다운: 수정안 제작 중 / 교체 완료 / A/B 테스트 중 / 유지 / 보류 | 디자이너 |
| Q 조치일 | 날짜 | 디자이너 |
| R 메모 | 자유 | 디자이너 |

C~O열은 **판정 실행** 때마다 덮어씁니다(수정하면 경고가 뜹니다). A, B, P, Q, R열과 행 순서는 건드리지 않습니다.

## 동작 규칙

- 작업물 ID가 매핑 탭에 새로 생기면 다음 판정 실행 때 맨 아래에 한 줄이 추가됩니다. 행을 지우지는 않습니다.
- 판정이 아직 없는 작업물은 C~O열이 비어 있습니다(광고 상품과 게시일만 채워짐).
- 교체되어 더 이상 데이터가 없는 작업물은 **마지막으로 판정된 주**를 보여 줍니다. 최근 주차(E열)로 오래된 줄을 알아볼 수 있습니다.
- 주차별 이력은 판정 탭에서 봅니다. 이 탭은 작업물당 최신 한 줄만 보여 줍니다.
- **성공 기준 4번**("알림 소재 중 1건 이상이 교체 또는 A/B 테스트로 이어짐")은 O열에 알림이 있던 줄의 P열이 `교체 완료` 또는 `A/B 테스트 중`인지로 확인합니다.

## 기존 템플릿이 생기면

컬럼 대응만 바꾸면 됩니다. 자동 열의 계산은 `Banner.gs`의 `computeBannerAutoCols_`에 있고, 열 위치는 `BANNER` 상수와 `Config.gs`의 `HEADERS[SHEETS.BANNER]`에 있습니다.
