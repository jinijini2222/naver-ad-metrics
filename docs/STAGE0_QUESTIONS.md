# 0단계 사전 준비: 브라우저 AI 수집 질문 목록

0단계에서 브라우저 AI가 공식 문서(naver/searchad-apidoc, 네이버 광고 가이드)를 보고 확인할 수 있는 질문이다.
각 질문은 그대로 붙여 넣어 쓸 수 있게 답변 형식까지 적었다.

## 공통 지시 (첫 메시지에 한 번)

> 네이버 검색광고 API 공식 문서(github.com/naver/searchad-apidoc 및 naver.github.io/searchad-apidoc)만 근거로 답해 주세요. 문서에서 확인되지 않으면 "확인 불가"라고 쓰고, 추측하지 마세요. 답마다 근거가 된 문서 URL이나 파일 경로를 붙여 주세요.

## A. 인증 (1단계 코드 검증)

1. API 요청에 필요한 헤더 이름을 모두 알려 주세요. (`X-Timestamp`, `X-API-KEY`, `X-Customer`, `X-Signature`가 맞는지)
2. 서명 생성 방식을 알려 주세요. 서명 대상 문자열의 조합(타임스탬프, HTTP 메서드, 경로를 구분하는 문자)과 해시 알고리즘, 인코딩이 무엇인지, 쿼리스트링을 서명에 포함하는지 알려 주세요.
3. 타임스탬프 단위(밀리초 여부)와 허용 오차를 알려 주세요.
4. 인증 실패 시 응답 코드와 에러 메시지 예시를 알려 주세요.

## B. 소재 목록 (2단계 코드 검증)

5. 캠페인 목록 조회 엔드포인트와 응답 필드를 알려 주세요. 특히 캠페인 ID, 이름, 유형 필드명과 유형 값(`WEB_SITE`, `SHOPPING` 등)을 전체 목록으로 알려 주세요.
6. 광고그룹 목록 조회 엔드포인트와 필수 쿼리 파라미터, 응답의 ID·이름 필드명을 알려 주세요.
7. 광고(소재) 목록 조회 엔드포인트와 필수 파라미터, 응답의 ID 필드명을 알려 주세요. 광고 유형(`type`) 값 전체 목록도 알려 주세요.
8. 쇼핑검색광고 소재(쇼핑몰 상품형 등)는 어떤 엔드포인트로 조회하나요? 일반 광고 목록(`/ncc/ads`)에 포함되나요?
9. 파워링크 이미지형 확장소재를 조회하는 엔드포인트와 필수 파라미터를 알려 주세요. 확장소재 `type` 값 전체 목록과 이미지형에 해당하는 값을 알려 주세요.
10. 목록 조회에 페이징이나 최대 건수 제한이 있나요? 있다면 방식을 알려 주세요.

## C. 성과(stats) (2단계 코드 검증)

11. 성과 조회 엔드포인트(`/stats` 등)의 파라미터를 모두 알려 주세요. `ids`, `fields`, `timeRange`, `datePreset`, `breakdown` 등 각각의 형식(JSON 문자열 여부)과 예시 요청 URL을 알려 주세요.
12. 지표 `fields`로 쓸 수 있는 값 전체 목록을 알려 주세요. 아래 항목에 해당하는 정확한 필드명을 각각 알려 주세요.
    - 노출수, 클릭수, 광고비
    - 전환수, 전환매출 (직접전환과 간접전환 구분 여부 포함)
    - 평균 노출 순위
13. 한 번에 조회할 수 있는 `ids` 최대 개수를 알려 주세요.
14. `timeRange` 최대 조회 기간(92일이 맞는지)과 날짜 형식을 알려 주세요.
15. 응답 JSON 구조 예시를 알려 주세요. `data` 배열 안의 행에 소재 ID가 어떤 필드로 들어 있는지, 데이터가 없는 소재는 응답에서 빠지는지 0으로 오는지도 알려 주세요.
16. 쇼핑검색광고와 확장소재도 `/stats`에서 소재 ID로 조회되나요? 소재 유형별로 조회 가능한 지표가 다른가요?
17. 전환 지표는 집계가 늦게 반영되나요? 확정까지 걸리는 기간이 문서에 있나요?
18. 일별 분리 조회가 가능한가요? 주간 합계와 일별 합산 중 무엇을 권장하나요?

## D. 호출 제한과 오류

19. 호출 제한(초당·일일 요청 수)과 초과 시 응답 코드(429 여부)를 알려 주세요.
20. 재시도 권장 방식이나 `Retry-After` 헤더 안내가 있나요?
21. 공통 에러 코드와 메시지 형식을 알려 주세요.

## E. 권한과 안전성

22. API 키 발급 위치와 절차를 알려 주세요. (광고주센터 메뉴 경로, 키 이름: 액세스라이선스, 비밀키, 고객 ID)
23. 조회 전용으로 제한된 키나 권한 구분이 있나요? 읽기 전용 계정 권한(마케터 계정이 아닌 별도 조회 권한)을 만들 수 있나요?
24. 대행사나 관리 계정 하위 광고주를 조회할 때 `X-Customer` 값은 무엇으로 넣나요?

## F. 성과형 디스플레이 (Phase 2 판단용)

25. 2025년 9월 1일 검색광고와 성과형 디스플레이 광고주센터 통합 이후 API 변경 공지가 있나요? 변경 날짜와 내용을 알려 주세요.
26. 성과형 디스플레이 캠페인·소재·성과를 조회할 수 있는 공식 API가 있나요? 있다면 엔드포인트와 지표를 알려 주세요.
27. 성과형 디스플레이에서 구매완료 등 신규 전환 지표를 API로 받을 수 있나요?
28. 성과형 디스플레이 API가 검색광고 API와 같은 인증과 호스트를 쓰나요, 별도 API인가요?

## G. 공식 문서 외 (브라우저 AI로 확인 어려움, 사람이 확인)

- [ ] 마케터의 API 키 발급 협조 가능 여부와 일정
- [ ] 키 전달 방식(스크립트 속성에 직접 입력할지)
- [ ] 실제 계정의 쇼핑검색 소재 구조(상품 단위인지, 광고그룹 단위인지)
- [ ] 광고주센터에서 보고서를 내려받을 수 있는지(키 발급 지연 시 대안)
